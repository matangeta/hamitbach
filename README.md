# המטבח

אפליקציית מטבח אישית: מתכונים, רשימת קניות, דברים שרוצים לקנות ומסעדות. לכל משתמש חשבון משלו, ואפשר לשתף כל קטגוריה עם משתמשים אחרים (צפייה או עריכה), או לשלוח מתכון בודד בקישור.

**כתובת:** https://matangeta.github.io/hamitbach/

- `index.html`, `app.js`: האפליקציה (PWA, אפשר להתקין למסך הבית)
- `config.js`: כתובת הפרויקט ב־Supabase והמפתח הציבורי (מותר שיהיה ציבורי; ההרשאות נאכפות במסד הנתונים)
- `supabase/schema.sql`: הטבלאות וחוקי ההרשאות (Row Level Security)
- `vendor/`: supabase-js, marked, DOMPurify
